POSIBLES REGLAS

Para certificarse como API:
- Tiene asociado el marcador de API
- Esta encapsulado en un auxiliar EVC,EPC,LDC
- En la tercera seccion tiene alguna de estas palabras: public, partner o private.
- Esta encapsulado en un auxiliar con un nombre diferente a EVC,EPC,LDC pero tiene un marcador de API o el conteo de marcador de api coincide con la cantidad de componentes dentro de el.
- Esta encapsulado en una capa de despliegue (mci o federado) y tiene un marcador de API o el conteo de marcador de api coincide con la cantidad de componentes dentro de el.
- UNA API SIEMPRE ESTA UBICADA EN INTEGRACION O EN SISTEMAS EXTERNOS.

Para certificarse como Evento:
- Puede estar encapsulado dentro de una capa de despliegue (MCI)
- No tiene marcador API
- Debe tener una capa de topicos
- La tercera seccion debe tener el tipo (aplicacion o empresarial) y la clasificacion ser igual a event, command o query.

Para certificarse como servicio
- No tiene marcador API
- Puede estar en integracion (servicio gestionado) o en sistemas externos o productor (servicio no gestionado).
