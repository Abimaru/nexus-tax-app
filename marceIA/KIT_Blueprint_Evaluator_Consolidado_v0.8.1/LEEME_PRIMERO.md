## Procedimiento de piloto

- Confirmar permisos y que Copilot **recupera reglas específicas** del Markdown, no solo que puede abrir la URL.
- Adjuntar PDF y JSON generados por Evidence Studio. La tercera ranura queda libre solo si la recuperación desde Azure está comprobada.
- Ejecutar nuevo chat, confirmar cinco parámetros, comprobar uso de Skills y la matriz requisito–instancia.
- Si Azure no funciona, adjuntar el Markdown como tercer archivo y no presumir conocimiento persistente.
- No se incluyen imágenes deliberadamente. La precisión de colores e iconos por componente seguirá limitada a lo que demuestre el extractor.
