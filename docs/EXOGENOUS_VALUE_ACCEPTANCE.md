# Aceptación provisional de valores exógenos

La acción **Usar valor de la exógena provisionalmente** está disponible en
Requisitos, Hechos, Conciliaciones, Matriz y Hallazgos.

Antes de guardar muestra entidad, concepto, valor, hoja, fila, categoría,
requisito, estado documental e impacto en la matriz. Exige un motivo; “Otro
motivo” y “cobrado para un tercero” exigen observación.

## Premios y ganancias ocasionales

El flujo pregunta si la operación corresponde a un premio propio, fue cobrada
para un tercero, no se reconoce o requiere revisión. Un premio propio puede
quedar como candidato provisional. No se calcula impuesto ni se presume que el
valor completo sea gravable.

Si fue cobrado para un tercero, se conserva el registro, se solicita explicación
y solo se permite un alias o relación opcional. No se excluye automáticamente y
se muestra como decisión pendiente de revisión profesional o documental.

## Documento posterior

La conciliación existente sugiere asociaciones por entidad, categoría, concepto
y valor. Al confirmarla, la aceptación se marca como respaldada si el valor
coincide, contradicha si difiere o no comparable cuando representa otro dato.
La decisión anterior y su historial no se eliminan.
